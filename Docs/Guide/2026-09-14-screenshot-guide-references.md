# 이용가이드 개편 기준 (2026-09-14)

대상: 현재 Studio5 하입치즈 이용가이드. 기존 검정·주황 디자인 유지. 실제 iOS 앱에서 예시 작품을 직접 작성하고 캡처한다. 생성 이미지로 UI를 재현하지 않는다.

## 적용 결정
- 주 구조: 크랙의 단계별 제작 순서. 우리 실제 UI 명칭인 기본 정보→세계관 및 핵심설정→등장인물 및 장소→시작 장면→진행 설정→완성 전 확인 사용.
- 케이브덕에서 필수/선택 구분과 제작/플레이 분리만 참고.
- 베이비챗에서 입력 내용과 화면 효과·적용 시점 설명 방식을 참고.
- 각 단계는 실제 캡처 + 누르는 위치 + 이 예제에서 넣은 내용 + 다음 확인 사항으로 구성.
- 기존 하입치즈 검정 배경, 흰 본문, 주황 버튼/순서 표식을 유지한다. 경쟁사 문구·이미지·화면은 게시물에 복제하지 않는다.
- 캡처 예제: 왕궁의 오랜 약속 / 서윤 / 하입치즈 작가. 별도 QA 앱의 메모리 저장소에서 작성. 개인 대화나 계정 정보는 공개하지 않는다.
- 이미지 전체 보기 링크, 고유 alt, 실제 dimensions, lazy loading, 모바일 단일 열. 작은 화면에서도 입력 예시를 이미지 밖 텍스트로 제공한다.
