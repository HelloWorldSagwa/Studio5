## 관련 문서와 앱 데이터

- 제작 매뉴얼, 홈페이지 진입 링크, 기존 가이드 공개 공지·피드를 함께 갱신했다. 공지 ID·최초 공개일은 보존하고 수정 시각을 추가했다. 새 앱 버전 출시를 꾸며내지 않았다.
- `SAI/SAI/Resources/hypecheese-feed.json`은 공개 피드와 일치하도록 갱신했다. 앱의 다른 진행 중 변경은 이 작업에 포함하지 않았다.
- 개인정보처리방침의 LM Studio 단독 처리 설명을 현재 Google Gemini 연결 사실로 보완했다. 앱은 공개 웹 문서를 직접 읽으므로 별도 본문 복사가 없다. 기존 가입 동의 버전과 범위는 소급 변경하지 않았다.
- 공급자 조건은 [Gemini API 약관](https://ai.google.dev/gemini-api/terms)을 2026-09-21 확인했다. 무료 서비스의 개선 활용·사람 검토 가능성을 조건부로 안내했다.

## 별도 출시 점검 사항

Gemini의 공식 약관은 18세 미만이 이용할 가능성이 있는 API 클라이언트도 제한한다. 현재 앱 가입은 14세 이상이며 실제 성인 인증 구현은 확인되지 않았다. 또한 현재 연결 프로젝트의 유료·무료 처리 조건, 처리 국가·보유기간, 동의 절차의 확정은 웹 사용법 정정만으로 완료되지 않는다. 이 작업에서 앱 가입 조건이나 기존 동의 기록을 임의로 변경하지 않았다.

시스템 단축어, 작가 시험 결과 화면, 정확한 서버 토큰 계측, 실제 용량 추가 과금·캐싱은 완료된 사용 기능으로 소개하지 않았다.

## 첫 사용 안내와 토큰 설명 재작성

- 출시 전 앱의 사용법에 맞게 ‘예전의’, ‘바뀐 방식’, ‘없어졌다’ 같은 변경 이력 표현을 제거했다. 자동 저장과 시작 장면은 사용 순서로 설명한다.
- `제미나이3플래시 무료티어 연동`의 사용자 요청 `01a0bf15-1c3a-7b50-af6b-34d3ad1c745d`에서 10,000토큰 초과분에 1,000토큰마다 2치즈를 안내하도록 정한 내용을 확인했다. `01a0bf15-db85-72e2-afaa-ec3364e2f0d3`의 구현 범위와 현재 코드 모두 실제 용량 추가 차감은 미구현이다.
- 제작 매뉴얼에 독립 목차 `#token-quote`를 만들었다. 입력·출력 토큰과 치즈, 설정량에 포함되는 텍스트, 여러 시작의 최대값, 35% 여유분과 100단위 올림, 기본 포함 10,000과 작성 한도 64,000의 차이, 모델별 예상 요금과 실제 차감을 설명한다. 기존 앵커는 보존했다.
- 현재 검증 한도는 여유분 적용 전 추정치이고 상단 견적은 보정 후 값이므로, 두 숫자를 같은 제한으로 안내하지 않는다. 실제 모델 토큰 계측이라고 표현하지 않는다.
- Basic의 10,100·11,000→32, 11,100·12,000→34, 15,000→40치즈를 확인했다. 기본 추정 8,000→상단 10,800→예상 32치즈와 출력량 1.25×→실제 캐릭터 비용 38치즈도 코드 계산과 일치한다.
- 최신 완료 대화 `01a0c11c-b564-78d3-bd45-f28eb7f30db5`, `01a0c120-25ee-7d42-a055-4bc0987c09ae`와 `StoryViews.swift`에서 현재 상태의 텍스트 표시·주황색 위아래 선·추천 답변이 마지막인 순서를 확인해 반영했다. 진행 중인 대화 삭제·분기는 완료 기능으로 추가하지 않았다.
- 공개 공지와 웹·앱 피드의 소개도 첫 사용 안내로 맞췄다. 요금표의 모델명과 금액이 모바일에서 끊어지지 않도록 보완했다.
