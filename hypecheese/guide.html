01

시작하기

하입치즈는 내가 고른 행동으로 이야기를 진행하고, 그 안의 캐릭터와 개인 대화를 이어가는 앱입니다. 홈의 스토리 상세에서 캐릭터 소개를 열어 본편을 플레이하기 전에 독립 대화를 시작하거나, 작가센터 → 내 스토리 만들기에서 직접 작품을 만들 수 있습니다.

  1. 가입하기. 만 14세 이상 여부와 필수 동의를 확인한 뒤, 캐릭터가 나를 부를 이름을 정합니다. 실명을 입력할 필요는 없습니다.
  2. 페르소나 정하기. 페르소나는 AI가 인식하는 ‘나’입니다. 이름과 설명을 바꾸면 대화에서 나를 부르고 이해하는 기준이 달라집니다. 캐릭터 자체를 바꾸는 설정은 아닙니다.
  3. 홈에서 선택하기. 홈의 취향 탭과 스토리 목록에서 작품을 고릅니다. 스토리 상세의 캐릭터 소개에서 독립 대화를 시작할 수도 있습니다. 직접 작품을 만들려면 작가센터 → 내 스토리 만들기로 이동합니다.

이름과 페르소나는 나중에도 관리 화면에서 바꿀 수 있습니다. 성별과 선호 스토리는 선택 항목이며 서로 다른 설정입니다. 현재 로그인 버튼은 외부 소셜 계정 인증 없이 기기 안의 이용 상태를 만드는 방식으로 동작합니다.

02

작품 만들기

작가센터 → 내 스토리 만들기에서 AI가 참고할 세계, 인물, 시작 장면과 진행 목표를 정합니다. 잘 만든 소개 문장 하나보다, 서로 모순되지 않는 설정이 중요합니다.

1. 세계와 플레이어의 위치를 정해요

이야기의 시간·장소, 세계의 규칙, 사용자가 맡을 역할을 작성합니다. ‘어떤 일이 가능한가’와 ‘사용자는 왜 여기 있는가’를 먼저 정하면 시작 장면을 만들기 쉽습니다.

예시

밤마다 책의 기억이 사라지는 도서관. 사용자는 잃어버린 책을 찾으러 온 방문객이다. 봉인된 서고는 사서의 허락 없이 열 수 없다.

2. 캐릭터의 성격·말투·관계를 구체화해요

캐릭터가 원하는 것, 말하는 방식, 사용자와의 처음 관계를 정합니다. ‘친절하다’에 그치지 않고 어떤 호칭을 쓰는지, 낯선 사람에게 어느 정도 거리를 두는지 적어 보세요. 여러 인물이 있다면 각자의 역할과 알고 있는 정보를 나눕니다.

예시

사서 서온은 존댓말을 쓰며 방문객을 ‘손님’이라고 부른다. 책을 아끼지만 처음 만난 사람에게 서고의 비밀을 먼저 알려주지는 않는다.

3. 공개 소개를 따로 확인해요

공개 소개는 이용자가 캐릭터를 이해하고 개인 채팅을 시작할 때 참고하는 정보입니다. 작가만 알아야 할 반전이나 아직 공개되지 않은 비밀을 소개에 그대로 넣지 마세요. 공개 정보와 작가의 전체 제작 설정은 역할이 다릅니다.

4. 시작 장면과 첫 행동을 정해요

시작 장소, 인물의 첫 대사, 사용자가 바로 할 수 있는 행동을 연결합니다. 첫 화면을 본 사람이 ‘지금 무엇을 하면 되는지’ 알 수 있어야 합니다.

5. 목표와 완료 후 흐름을 정해요

도달할 목표와 성립 조건을 적습니다. 목표에 적은 결말은 이미 일어난 일이 아닙니다. 사용자의 행동과 이야기 진행으로 조건이 맞아야 달성됩니다. 목표를 이룬 뒤 계속 진행할지, 마지막 장면이나 에필로그로 마무리할지도 확인합니다.

6. 저장하고 직접 플레이해요

저장한 작품을 열어 시작 장면, 인물의 말투, 추천 행동, 목표가 의도대로 이어지는지 확인합니다. 본편에서 인물과 대화한 뒤 개인 채팅까지 열어, 같은 인물로 느껴지는지도 점검하세요.

현재 테스트 버전의 작품과 이미지는 기기에 저장됩니다. 저장·공개 설정 변경을 다른 기기로의 동기화나 실제 전체 이용자 대상 배포로 해석하면 안 됩니다. 표지 AI 생성을 선택하면 제목·요약·스타일·입력 프롬프트가 연결된 이미지 생성 서버로 전송됩니다.

03

스토리챗 진행하기

  1. 작품을 열고 시작 장면을 읽습니다. 내가 맡은 역할과 주변 상황을 확인합니다.
  2. 내 행동을 입력합니다. 말하거나 살펴보거나 선택할 행동을 구체적으로 적습니다. 추천 행동은 바로 사용할 수 있는 선택지이며, 직접 다른 행동을 입력해도 됩니다.
  3. 장면과 인물의 반응을 확인합니다. AI가 서술과 대사로 이어갑니다. 목표나 상태 변화가 있다면 실제 진행 내용과 함께 확인합니다.
  4. 만난 인물과 개인 대화를 이어갑니다. 본편에서 캐릭터 채팅으로 이동하면 해당 회차의 확정된 사건과 관계를 바탕으로 대화합니다.
내 행동을 적는 방법

“다음으로 넘어가”보다 “나는 찢어진 책장을 서온에게 보여주며 이 책이 어느 서가에 있었는지 물었다”처럼 행동과 목적을 함께 적어 보세요.

새 회차를 시작하면 별도의 진행 기록이 만들어집니다. 이전 회차를 플레이하며 생긴 사건이 새 회차에서 이미 일어난 일로 이어지는 것은 아닙니다. 기존 회차의 기록은 별도로 남습니다.

04

두 가지 캐릭터챗

같은 캐릭터여도 어디에서 대화를 시작했는지에 따라 참고하는 과거가 다릅니다.

캐릭터챗 시작 경로와 기억 범위
시작 경로대화가 이어지는 기준
홈 → 스토리 상세 → 캐릭터 소개본편을 플레이하지 않고 독립 캐릭터챗을 시작합니다. 캐릭터의 공개 설정과 이 독립 채팅방의 대화·기억을 참고합니다. 사용자가 플레이하지 않은 본편 사건을 함께 겪은 과거로 삼지 않습니다.
본편에서 인물에게 접근연결된 회차에서 확정된 사건, 그 인물과의 관계, 이 개인 채팅방의 대화·기억을 참고합니다.

본편을 더 진행한 다음 돌아와도 되나요?

기존 연계 채팅방으로 돌아오면 연결된 회차의 새로운 확정 기록을 참고해 이어갑니다. 다른 회차의 사건이나 다른 인물과만 나눈 개인 대화는 이 방의 공동 경험이 아닙니다.

같은 캐릭터의 방이 여러 개 생길 수 있나요?

네. 스토리 상세의 캐릭터 소개에서 시작한 독립 대화, 특정 회차에 연결된 대화, 새로 만든 대화방은 구분됩니다. 방을 고를 때 연결된 작품과 대화 내용을 확인하세요.

기억을 확인하는 예시

본편에서 열쇠를 함께 찾았다면 연계 채팅방에서 “아까 열쇠를 찾았을 때 어땠어?”라고 이어갈 수 있습니다. 다른 방에서만 정한 비밀 암호는 이 방의 기억으로 넘어오지 않아야 합니다.

AI가 잘못 회상하거나 없는 의미를 덧붙일 수 있습니다. 중요한 사실은 AI의 기억을 열어 확인하고, 틀린 부분을 직접 고쳐 주세요. 모든 대화 원문이 기억에 그대로 보관되는 방식은 아닙니다.

05

채팅방 설정

스토리챗과 캐릭터챗 오른쪽 위 메뉴에서 대화에 사용할 설정을 확인합니다.

페르소나
캐릭터가 인식할 나의 이름과 설정을 선택합니다. 예를 들어 같은 캐릭터와도 ‘여행자 민’과 ‘도서관 견습생 민’으로 다른 역할을 정할 수 있습니다. 관리에서 페르소나를 추가·수정하고 방에서 선택합니다. 과거 대화 원문까지 다시 쓰는 기능은 아닙니다.
사용자 노트
이 방에서 AI가 계속 참고할 사용자 정보와 대화 선호를 직접 적습니다. 예: “나는 커피를 마시지 않아”, “나를 민이라고 불러줘”. 입력한 내용은 저장한 뒤 다음 생성부터 참고합니다. 이미 일어난 사건을 자동으로 기록하는 AI의 기억과 구분해 사용하세요.
출력량
AI가 한 번 답할 때 사용할 출력 토큰 예산을 조절합니다. 토큰은 글자 수와 다른 단위로, 언어와 문장에 따라 글자 수가 달라집니다. 2×를 선택해도 항상 글자 수가 정확히 두 배가 되는 것은 아닙니다. 출력량을 높이면 답변이 길어질 수 있습니다. 캐릭터챗에서는 출력량이 1회 치즈 비용에도 반영됩니다. 현재 로컬 테스트의 스토리챗은 치즈를 차감하지 않습니다.
AI의 기억
이 방의 진행과 중요한 사실을 자동으로 정리한 내용을 확인하고 보정합니다. 아래 네 구역으로 구성됩니다.
새 채팅방
현재 방의 대화와 별개인 새 방을 만듭니다. 이전 방의 사용자 노트·대화·개인 기억을 그대로 복사하지 않습니다. 본편 연계 방에서 만들었다면 본편 연결은 유지될 수 있으므로, 개인 기억 초기화와 본편 경험의 삭제를 같은 뜻으로 보지 마세요.

사용자 노트와 출력량은 해당 방 또는 스토리 회차에 적용됩니다. 다른 방으로 옮긴 뒤에는 그 방의 설정을 확인하세요. 편집 화면에서 저장하지 않고 돌아가면 기존 내용이 유지됩니다.

06

AI의 기억 확인·수정하기

메뉴의 AI의 기억은 매번 대화 원문 전체를 보여주는 화면이 아니라, 다음 대화에 필요한 내용을 정리해 두는 곳입니다. 자동 정리 이후에도 사용자가 내용을 고칠 수 있습니다.

진행 흐름
이 방에서 지금까지 어떻게 이야기가 이어졌는지 큰 흐름을 정리합니다.
최근 변화
방금 달라진 상황과 최근 사건을 적습니다. 찾던 물건을 찾았다면 현재 상태가 ‘찾음’으로 맞는지 확인하세요.
인물과 관계
주요 인물과 사용자 사이의 관계, 실제로 변화한 거리감과 역할을 정리합니다.
약속과 중요 사실
명확하게 나눈 약속, 호칭, 취향, 다시 떠올려야 할 정보를 적습니다.
  1. 메뉴에서 AI의 기억을 엽니다.
  2. 틀린 이름·시점·관계를 해당 구역에서 고칩니다. 일어나지 않은 일을 지우고, 필요한 사실을 짧고 명확하게 적습니다.
  3. 저장한 뒤 대화를 이어갑니다. 자동 정리는 이후 대화 내용에 따라 다시 갱신될 수 있습니다.
현재 상태를 분명하게

“청동 열쇠를 찾는 중”이 남아 있는데 이미 찾았다면 “서온과 청동 열쇠를 찾았다. 다음에는 봉인된 서고를 확인하기로 했다”처럼 고쳐 보세요.

요약 과정에서 세부 내용이 빠지거나 관계의 의미가 과장될 수 있습니다. 지속적으로 유지해야 할 내 정보는 사용자 노트에도 명확히 적고, 실제 사건·약속은 AI의 기억에서 확인하면 도움이 됩니다. 다른 인물에게만 말한 비밀이나 다른 회차의 과거를 가져와 적으면 그 방의 사실과 충돌할 수 있습니다.

07

치즈와 출력 비용

치즈는 AI 대화에 사용하는 앱 안의 재화입니다. 홈의 잔액, 마이, 충전 화면과 두 채팅방의 햄버거 메뉴에서 보유량을 확인할 수 있습니다. 채팅방 메뉴에서는 닫기(X) 버튼 오른쪽에 잔액이 표시됩니다.

캐릭터챗과 스토리챗의 현재 비용

캐릭터챗: 선택한 모델의 기본 비용에 출력량 배율을 적용하고 소수점은 올림해 차감합니다. 모델과 출력량을 선택할 때 표시되는 1회 비용을 확인하세요.

스토리챗: 현재 로컬 테스트에서는 치즈를 차감하지 않습니다. 스토리챗의 요금 적용은 아직 연결하지 않았으며, 정식 적용 조건이 정해지면 별도로 안내합니다.

무료 치즈와 구매 치즈
충전 화면에서 각각의 보유량을 구분해 확인합니다. 무료 지급분은 지급 조건에 따라 만료될 수 있으며, 남은 무료 치즈가 먼저 사용됩니다.
출석
현재 테스트 버전은 하루 한 번 출석 치즈 50개를 제공합니다. 출석 지급분은 지급 후 21일 동안 사용할 수 있습니다. 화면의 수령 여부와 가장 가까운 만료일을 확인하세요.
모델과 출력량
캐릭터챗은 선택한 모델의 기본 비용에 출력량이 반영됩니다. 긴 답변을 선택할수록 비용이 커질 수 있습니다. 화면에 보이는 모델 이름은 앱의 선택 등급이며, 현재 테스트에서는 연결된 로컬 모델로 응답을 생성합니다.
캐릭터챗 잔액이 부족할 때
충전·출석 화면에서 잔액을 확인한 뒤 원래 대화로 돌아옵니다. 결제나 충전이 완료되기 전에 같은 요청을 반복해 보내지 마세요.

결제와 생성 실패는 어떻게 확인하나요?

현재 개발용 구매 모드는 실제 결제를 하지 않는 테스트 충전입니다. 실제 결제가 가능한 환경에서는 구매 화면의 상품·가격과 App Store 확인 내용을 따릅니다. 테스트 지급을 현금 구매나 환불 완료로 간주하지 마세요.

전송 오류가 나면 먼저 기존 입력과 답변 상태, 잔액을 확인합니다. 재시도·취소·복구 처리는 생성 단계에 따라 달라질 수 있으므로, 모든 실패가 자동으로 환급된다고 가정하지 마세요. 비용이나 결제 상태가 맞지 않으면 발생 시각과 해당 화면을 문의로 보내 주세요. 비밀번호·결제수단 번호·대화의 민감한 내용은 보내지 않아도 됩니다.

정식 유료 상품의 가격과 청약철회·환불 조건은 실제 제공 전에 안내합니다. 자세한 기준은 이용약관의 결제 안내를 확인하세요.

08

내 활동과 소식

좋아하는 작품과 캐릭터를 저장하거나 좋아요를 남기고, 작가를 팔로우해 다시 찾아갈 수 있습니다. 마이에서 내 작품과 활동을 확인하세요. 현재 테스트 버전의 활동 기록은 이 기기에 저장됩니다.

홈의 벨을 누르면 공지·알림·업데이트를 볼 수 있습니다. 공지와 업데이트는 공개 안내입니다. 현재 개인 알림은 내 작품에 다른 사용자가 남긴 댓글만 안내하며 해당 작품으로 연결됩니다. 읽은 상태는 저장되며, 아직 항목이 없으면 빈 목록이 표시됩니다.

댓글 알림은 소식함의 작가 알림 설정 또는 마이의 설정에서 켜거나 끌 수 있습니다. 이 선택은 앱 안의 댓글 알림에 적용됩니다. 광고 수신 동의나 iOS 푸시 알림 권한을 바꾸는 기능은 아닙니다.

이용가이드와 공지는 웹에서도 로그인 없이 읽을 수 있습니다. 앱 안의 소식 확인과 iOS의 시스템 푸시 알림 허용은 별개입니다.

09

계정과 데이터 보관

현재 계정 상태, 페르소나, 작품, 대화와 활동 기록은 기기에 저장됩니다. 다른 기기에 로그인한다고 자동으로 이어지지 않습니다. 앱 삭제나 기기 변경으로 로컬 기록을 잃을 수 있습니다.

  • 로그아웃: 이용 상태를 종료합니다. 이 기기의 기록 삭제와는 다릅니다.
  • 회원탈퇴: 설정 → 계정 및 개인정보 → 회원탈퇴에서 이 기기의 회원 데이터를 삭제합니다. 페르소나·작가 프로필, 작품·이미지, 채팅·활동·동의 기록과 보유 재화가 삭제됩니다.
  • 기기 설정: 테마·햅틱 같은 기기 설정은 유지됩니다. 운영체제 백업이나 이미 외부 AI 서버로 전송한 정보까지 같은 작업으로 삭제되는 것은 아닙니다.

기기에 저장한다고 AI 답변도 기기 안에서만 만드는 것은 아닙니다. 필요한 대화와 설정이 연결된 AI 서버로 전송됩니다. 범위는 개인정보처리방침의 AI 처리 안내에서 확인하세요.

10

자주 묻는 질문과 문의

페르소나를 바꾸면 캐릭터가 바뀌나요?

페르소나는 AI가 인식하는 ‘나’를 바꿉니다. 상대 캐릭터를 바꾸는 기능은 아닙니다. 기존 대화 원문은 그대로 남으므로 역할을 완전히 새로 시작하려면 새 채팅방도 고려하세요.

다른 방에서 했던 말을 왜 모르나요?

방과 회차마다 대화·기억의 범위가 다릅니다. 다른 인물과의 개인 대화나 별도 회차의 사건은 자동으로 공유되는 과거가 아닙니다.

AI가 예전 상황으로 돌아갔어요.

AI의 기억에서 최근 변화와 약속을 확인하고 현재 상태를 짧게 고쳐 저장하세요. 실제 사용 모델과 문맥에 따라 시제나 해석 오류가 생길 수 있습니다.

출력량을 늘렸는데 답변이 정확히 두 배는 아니에요.

출력량은 글자 수가 아니라 출력 토큰 예산을 조절합니다. 답변 내용과 언어에 따라 실제 길이가 달라질 수 있습니다.

대화가 멈추거나 연결 오류가 나요.

네트워크와 연결된 AI 서버 상태를 확인합니다. 화면에 저장된 입력이 있는지 먼저 확인하고 제공되는 재시도 기능을 이용하세요. 앱을 삭제해서 해결하려 하면 로컬 기록을 잃을 수 있습니다.
