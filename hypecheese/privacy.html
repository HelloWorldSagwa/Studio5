01

운영자와 적용 범위

Studio5는 하입치즈의 개인정보 처리 내용을 다음과 같이 안내합니다. 이 방침은 하입치즈 앱의 계정 서버·기기 저장소·연결된 AI 서버와 하입치즈 안내 웹페이지에 적용됩니다.

개인정보처리방침은 처리 내용을 알리는 문서입니다. 열람 자체를 모든 개인정보 처리에 대한 동의로 보지 않습니다. 현재 공개된 가입 동의 문서에는 과거 로컬 버전의 범위가 남아 있으므로 이를 현재 서버 처리 전체의 동의로 해석하지 않습니다. 가입 시의 개인정보 수집·이용 동의와 선택적 광고 수신 동의는 각각 별도로 확인합니다.

03

저장·보유·파기

회원 계정, 페르소나, 대화, 작품·활동·동의 기록과 재화 관련 정보는 계정 서버에서 관리하며, 화면 표시에 필요한 사본은 기기에도 저장할 수 있습니다. 로그아웃이나 기기의 앱 삭제만으로 서버 계정 데이터를 삭제하지 않습니다. 서버 계정 삭제 요청은 설정 → 회원탈퇴를 이용해 주세요.

설정 → 회원탈퇴에서 요청을 확인하면 계정 접근과 게시 작품의 공개를 중단합니다. 본인의 비공개 대화·미게시 작품·개인 이미지 등은 삭제 처리하고, 소셜 로그인 연결과 인증정보는 서버에서 삭제 처리합니다. 삭제 처리가 완료된 계정은 복구할 수 없습니다.

탈퇴 전에 다른 사용자가 이용을 시작한 스토리·채팅은 그 사용자가 계속 이용할 수 있습니다. 해당 작품 버전의 설정·이미지 사본과 기존 이용자의 대화·진행 기록은 기능 제공에 필요한 동안 유지합니다. 탈퇴 회원의 작품은 새 이용자를 위한 공개 목록·검색에 다시 노출하지 않습니다. 이 보관 범위는 홍보나 AI 학습을 위한 포괄적인 이용 허락이 아닙니다.

삭제 처리는 우선 접근 차단과 논리적 삭제로 반영되며, 즉시 모든 원본 파일·백업이 물리적으로 제거되는 것은 아닙니다. 데이터 종류별 최종 파기 기한과 백업 만료 조건은 아직 확정된 안내가 아니며, 접근 차단을 모든 데이터의 최종 파기 완료로 보지 않습니다. 결제·정산·중복 처리 방지·분쟁 대응을 위한 기록과 법령상 보존이 필요한 정보는 해당 목적에 필요한 범위에서 일반 서비스 이용 데이터와 구분해 관리합니다. 이미 외부 서비스로 전송한 정보나 운영체제 백업은 별도 처리 범위를 확인합니다.

보관 범위에 대한 확인이나 추가 삭제 요청은 아래 개인정보 보호 문의로 접수할 수 있습니다. 문의 처리 목적이 끝난 정보는 지체 없이 삭제하는 것을 원칙으로 하며, 법령상 별도 보존이 필요한 경우 해당 근거와 기간을 안내합니다.

04

AI 처리와 전송 범위

2026.09.21 AI 연결 안내 보완. 기기 저장과 AI 처리는 서로 다릅니다. 현재 테스트 환경에서 Basic의 대화·스토리·추천 답변·기억 정리와 작가센터 텍스트 생성은 중계 서버를 거쳐 Google Gemini API로 전달됩니다. Heart·Deep은 연결된 LM Studio 서버를 사용합니다. 모든 텍스트가 LM Studio나 휴대전화 안에서만 처리되는 것은 아닙니다. 이 안내는 현재 연결 방식의 설명이며, 기존 가입 동의의 범위를 확장하지 않습니다.

  • 대화·스토리·추천 답변: 입력한 메시지와 필요한 대화 이력, 캐릭터·페르소나·작품 설정, 사용자 노트, 관련 기억·진행 기록을 전달합니다.
  • AI 기억 정리: 기존 기억과 최근 대화, 관련 설정과 확정 기록을 전달해 기억을 갱신합니다.
  • 작품 제작 보조: 작성한 아이디어와 해당 제작 설정을 텍스트 생성 서버에 전달합니다.
  • 표지 생성: 별도로 연결된 이미지 생성 서버에 제목·요약·선택한 스타일·입력 프롬프트를 전달합니다. 그 서버가 사용하는 후속 처리 환경은 텍스트 생성 서버와 같다고 가정하지 않습니다.

이 요청은 이용자가 실행한 생성 기능에 필요한 처리를 위한 것입니다. 가입 동의를 대화 원문의 포괄적인 학습 활용, 제3자 제공 또는 국외 이전 동의로 확장하지 않습니다.

Google의 Gemini API 약관에 따르면 무료 서비스에 입력한 내용과 생성 결과는 서비스·머신러닝 개선에 사용되거나 사람이 검토할 수 있습니다. 실제 적용 조건은 연결 프로젝트의 유료·무료 상태 등에 따라 달라지며, 앱의 치즈 차감 여부가 이를 결정하지 않습니다. 무료 서비스에는 민감한 정보·기밀·개인정보를 입력하지 마세요.

정식 서비스에 적용할 처리 국가, 서버 로그 보유기간, 제공 조건과 필요한 동의 절차는 아직 확정된 안내가 아닙니다. 이 문서가 무저장·무학습 또는 국외 이전 절차의 완료를 보장하지 않습니다. 실제 처리 조건이 정해지면 수신자·목적·항목·기간·국가·방법·근거와 필요한 선택 절차를 별도로 안내합니다.

05

외부 서비스와 정보 제공

계정 인증과 데이터 저장·동기화에는 Supabase를 사용합니다. 생성 기능을 실행할 때는 위에 설명한 서버로 요청을 전송합니다. 공개 문서와 공지 자료는 Studio5의 Vercel 호스팅 웹사이트에서 제공합니다. 이메일 문의는 이용자가 선택한 이메일 서비스를 통해 Studio5 문의 주소로 전달됩니다.

실제 App Store 결제가 가능한 환경에서는 Apple의 결제 시스템이 결제수단과 거래를 처리합니다. 앱은 상품·거래 식별 및 처리 상태 등 재화 지급에 필요한 정보를 사용하며 결제 카드번호를 직접 입력받지 않습니다. 현재 개발용 모의 충전은 실제 금전 결제와 구분합니다.

새로운 처리위탁·제3자 제공·국외 이전이 생기면 제공 전에 해당 조건과 법적 근거를 안내합니다.

열람·정정·삭제·동의 철회

이용자는 개인정보의 열람, 정정·삭제, 처리정지와 동의 철회를 요청할 수 있습니다. 페르소나와 선호 설정은 앱에서 수정할 수 있고, 회원 데이터 삭제는 설정 → 회원탈퇴에서 실행할 수 있습니다.

광고성 정보 수신 동의 철회는 아래 문의 주소로 요청할 수 있습니다. 광고 수신 동의와 iOS 알림 권한은 별개입니다. 광고 수신에 동의하지 않아도 기본 서비스를 이용할 수 있습니다.

앱에서 처리하기 어렵거나 이미 외부 서버로 보낸 정보에 관한 요청은 studiofiveteam@gmail.com으로 문의해 주세요. 요청 대상을 확인하는 데 필요한 최소한의 확인 후 관계 법령에 따라 처리합니다. 서비스가 보유하지 않은 비밀번호나 신분증을 문의에 먼저 첨부할 필요는 없습니다.

현재 보호 범위

앱은 기기 내 회원 접근 상태를 확인하고 회원 데이터와 기기 설정을 구분해 관리합니다. 회원탈퇴 시 앱이 관리하는 데이터와 미디어 삭제 경로를 제공합니다.

현재 AI 테스트 서버는 환경에 따라 HTTP로 연결될 수 있습니다. 이 방침으로 모든 전송 구간의 암호화나 정식 서버의 접근 통제가 완료되었다고 주장하지 않습니다. 신분증·계좌·비밀번호와 타인의 민감한 개인정보를 테스트 대화나 제작 설정에 입력하지 마세요. 정식 서버 도입 시 실제 전송·접근·보관·파기 조치를 확인해 공개합니다.
