01

운영자와 적용 범위

Studio5는 하입치즈의 개인정보 처리 내용을 다음과 같이 안내합니다. 이 방침은 현재 기기 내 저장소와 연결된 AI 서버를 사용하는 로컬 테스트 버전, 그리고 하입치즈 안내 웹페이지에 적용됩니다.

개인정보처리방침은 처리 내용을 알리는 문서입니다. 열람 자체를 모든 개인정보 처리에 대한 동의로 보지 않습니다. 가입 시의 개인정보 수집·이용 동의와 선택적 광고 수신 동의는 각각 별도로 확인합니다.

웹 문서를 요청하면 IP 주소, 브라우저와 기기에서 보내는 기본 요청 정보가 웹 호스팅 인프라를 거칩니다. 하입치즈 웹섹션 자체에는 회원 입력 양식, 광고 추적 스크립트나 분석 쿠키를 추가하지 않았습니다. 앱의 로컬 데이터는 이 문서를 열었다는 이유로 웹페이지에 전송되지 않습니다.

03

저장·보유·파기

현재 회원 상태, 페르소나, 대화, 작품·활동·동의 기록, 재화 관련 상태는 해당 기기의 앱 저장소와 앱이 관리하는 파일에 저장합니다. 회원탈퇴 또는 해당 기기의 앱 데이터 삭제 시까지 유지되며, 로그아웃만으로 삭제되지 않습니다. 클라우드 계정 서버와 기기 간 자동 동기화는 아직 연결하지 않았습니다.

설정 → 계정 및 개인정보 → 회원탈퇴를 실행하면 앱이 관리하는 회원 데이터와 이미지 파일을 삭제합니다. 테마·햅틱 같은 기기 설정과, 이전 데이터의 재유입을 막고 결제 계정을 구분하기 위한 기기 내 초기화 상태는 남습니다. 기기·운영체제의 백업 사본과 이미 AI 서버로 전송한 정보가 이 작업으로 함께 삭제되지는 않습니다.

이메일로 보낸 문의는 답변과 관련 요청 처리를 위해 사용하며, 처리 목적이 끝나면 지체 없이 삭제하는 것을 원칙으로 합니다. 법령상 별도 보존이 필요한 경우에는 항목·근거·기간에 따라 분리 보관합니다. 현재 테스트 기능에 실제 발생하지 않은 거래를 가정하여 일괄적인 법정 보유기간을 적용하지 않습니다.

향후 클라우드 저장이나 정식 유료 거래를 도입하면 실제 처리 항목, 보유기간, 탈퇴·파기 방식과 적용 시점을 사전에 공개합니다.

04

AI 처리와 전송 범위

기기 저장과 AI 처리는 서로 다릅니다. 현재 텍스트 생성 요청은 테스트 환경에 연결된 LM Studio 서버로 전달됩니다. 서버는 앱과 별도 프로세스·컴퓨터에서 동작할 수 있으므로 AI 처리가 항상 휴대전화 내부에서만 이루어진다고 보장하지 않습니다.

  • 대화·스토리·추천 답변: 입력한 메시지와 필요한 대화 이력, 캐릭터·페르소나·작품 설정, 사용자 노트, 관련 기억·진행 기록을 전달합니다.
  • AI 기억 정리: 기존 기억과 최근 대화, 관련 설정과 확정 기록을 전달해 기억을 갱신합니다.
  • 작품 제작 보조: 작성한 아이디어와 해당 제작 설정을 텍스트 생성 서버에 전달합니다.
  • 표지 생성: 별도로 연결된 이미지 생성 서버에 제목·요약·선택한 스타일·입력 프롬프트를 전달합니다. 그 서버가 사용하는 후속 처리 환경은 텍스트 생성 서버와 같다고 가정하지 않습니다.

이 요청은 이용자가 실행한 생성 기능에 필요한 처리를 위한 것입니다. 가입 동의를 대화 원문의 포괄적인 학습 활용, 제3자 제공 또는 국외 이전 동의로 확장하지 않습니다.

정식 클라우드 AI 제공자, 처리 국가, 서버 로그 보유기간과 학습 활용 조건은 아직 확정하지 않았습니다. 이 방침은 특정 제공자나 국가로의 이전 조건이 확정되었다는 안내가 아니며, ‘어떤 서버에서도 저장·학습하지 않는다’는 보장도 아닙니다. 새 제공자나 국외 이전을 도입하기 전 실제 수신자·목적·항목·기간·국가·방법·근거와 필요한 선택 절차를 안내합니다.

05

외부 서비스와 정보 제공

현재 계정과 콘텐츠를 외부 클라우드 데이터베이스에 동기화하지 않습니다. 생성 기능을 실행할 때는 위에 설명한 서버로 요청을 전송합니다. 공개 문서와 공지 자료는 Studio5의 Vercel 호스팅 웹사이트에서 제공합니다. 이메일 문의는 이용자가 선택한 이메일 서비스를 통해 Studio5 문의 주소로 전달됩니다.

실제 App Store 결제가 가능한 환경에서는 Apple의 결제 시스템이 결제수단과 거래를 처리합니다. 앱은 상품·거래 식별 및 처리 상태 등 재화 지급에 필요한 정보를 사용하며 결제 카드번호를 직접 입력받지 않습니다. 현재 개발용 모의 충전은 실제 금전 결제와 구분합니다.

새로운 처리위탁·제3자 제공·국외 이전이 생기면 제공 전에 해당 조건과 법적 근거를 안내합니다.

06

열람·정정·삭제·동의 철회

이용자는 개인정보의 열람, 정정·삭제, 처리정지와 동의 철회를 요청할 수 있습니다. 페르소나와 선호 설정은 앱에서 수정할 수 있고, 회원 데이터 삭제는 설정 → 계정 및 개인정보 → 회원탈퇴에서 실행할 수 있습니다.

광고성 앱 푸시 수신 선택은 같은 계정 및 개인정보 화면에서 변경할 수 있습니다. 광고 수신 동의와 iOS 알림 권한은 별개입니다. 광고 수신에 동의하지 않아도 기본 서비스를 이용할 수 있습니다.

앱에서 처리하기 어렵거나 이미 외부 서버로 보낸 정보에 관한 요청은 studiofiveteam@gmail.com으로 문의해 주세요. 요청 대상을 확인하는 데 필요한 최소한의 확인 후 관계 법령에 따라 처리합니다. 서비스가 보유하지 않은 비밀번호나 신분증을 문의에 먼저 첨부할 필요는 없습니다.

아동·청소년

현재 가입 기준은 만 14세 이상입니다. 만 14세 미만 아동을 위한 법정대리인 동의·확인 절차는 제공하지 않습니다. 가입 화면의 연령 확인은 성인 인증이나 미성년자의 유료 계약에 필요한 법정대리인 동의를 대신하지 않습니다.

08

현재 보호 범위

앱은 기기 내 회원 접근 상태를 확인하고 회원 데이터와 기기 설정을 구분해 관리합니다. 회원탈퇴 시 앱이 관리하는 데이터와 미디어 삭제 경로를 제공합니다.

현재 AI 테스트 서버는 환경에 따라 HTTP로 연결될 수 있습니다. 이 방침으로 모든 전송 구간의 암호화나 정식 서버의 접근 통제가 완료되었다고 주장하지 않습니다. 신분증·계좌·비밀번호와 타인의 민감한 개인정보를 테스트 대화나 제작 설정에 입력하지 마세요. 정식 서버 도입 시 실제 전송·접근·보관·파기 조치를 확인해 공개합니다.
